# Enemies

`Concepts` contains the current single-sprite combat artwork assigned to enemy
definitions.

`Source` keeps original sheets or pose files grouped by enemy. For example,
`Source/cultist/Fanatic_Poses.png` contains the full pose sheet used to produce
`Concepts/cultist.png`.

Use `Taskbar Tactics > Art > Import and Assign Enemy Artwork` after adding new
PNG files to `Concepts`.
